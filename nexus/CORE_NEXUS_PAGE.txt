[size=5][b]Mimic Party Modding Core[/b][/size]
[b]Runtime 1.0.0 · by arribbaa[/b]

The shared runtime foundation for independent Mimic Party mods. Provides build fingerprints, a mod registry, reflection helpers and guarded runtime patch transactions. The Core itself does not change gameplay or increase the player limit.

[size=4][b]Requirements[/b][/size]
[url=https://www.nexusmods.com/mimicparty/mods/3]BepInEx Pack for Mimic Party 1.0.1[/url]
Mimic Party Windows x64 / Steam, Unity 6000.4.2f1. The Pack provides BepInEx 6 IL2CPP x64 build 788 and the compatibility bootstrap. Do not use BepInEx 5 or a Mono loader. The 10 Player Expansion is NOT a Core requirement.

[size=4][b]Installation[/b][/size]
1. Close the game.
2. Install the BepInEx Pack into the folder containing Mimic Party.exe.
3. Extract the Core runtime ZIP into the same folder.
4. Install the feature mod you want to use and start normally through Steam.

This R4 archive installs BepInEx/plugins/MimicPartyModdingCore.dll. The Core DLL remains byte-for-byte identical to runtime 1.0.0; R4 updates compatibility documentation for the captured Mimic Party v0.2.3 build. BepInEx and Interop Bootstrap stay in the separate Pack.

Already using the older Expansion Complete package? Its Core DLL is the same version. Do not install renamed duplicates or delete the shared bootstrap in BepInEx/patchers.

[size=4][b]For mod authors[/b][/size]
The optional Developer Starter is a reusable C# source project, not an extra plugin for players to install. Declare the Core GUID com.arribbaa.mimicparty.moddingcore as a hard dependency and reference the installed DLL without copying it into your own distribution. Use your own unique GUID, title and author name for your independent mod.

[size=4][b]Compatibility and support[/b][/size]
R4 documents the captured v0.2.3 fingerprint while keeping Core 1.0.0 unchanged. The Core reports game fingerprints to dependent mods; each feature mod must validate the game build it patches. Use Pack 1.0.1 for the v0.2.3 compatibility bootstrap.
[url=https://github.com/LocoPablito/MimicParty-Modding/blob/main/COMPATIBILITY.md]Exact compatibility information[/url]

Close the game before removing the Core DLL. Remove it only after dependent mods; keep the Pack when other mods need it. Include versions and a sanitized BepInEx/LogOutput.log excerpt when asking for support. Do not post game binaries or private diagnostic archives.
