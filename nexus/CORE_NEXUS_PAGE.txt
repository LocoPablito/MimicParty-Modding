[size=5][b]Mimic Party Modding Core[/b][/size]
[b]Version 1.0.0 — by arribbaa[/b]

The shared runtime foundation for Mimic Party mods. Install it when a feature mod lists it as a dependency. The Core alone does not raise the player limit.

[b]Included[/b]
Core runtime 1.0.0 and the Interop Bootstrap 1.0.0 compatibility component. The bootstrap repairs the recognized generated CoreModule duplicate-helper issue locally; no Unity or game assembly is included.

[b]Required[/b]
Mimic Party for Windows/Steam, documented v0.1.73 build; BepInEx 6 Unity IL2CPP Windows x64 build 788.
[url=https://builds.bepinex.dev/projects/bepinex_be/788/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.788%2B5b766a3.zip]Official BepInEx download[/url]
BepInEx is NOT included. Do not use BepInEx 5 or a Mono build.

[b]Install[/b]
Close the game. Restore original game files first if an older mod patched GameAssembly.dll on disk. Extract official BepInEx into the folder containing Mimic Party.exe. Extract this package into the same folder before launching. Preserve the BepInEx/plugins and BepInEx/patchers paths. Then install your feature mods and start normally through Steam.

Already using the author's Complete 10 Player Expansion package? The Core is already included; do not install duplicate copies.

[b]Uninstall[/b]
Remove BepInEx/plugins/MimicPartyModdingCore.dll only when no installed mods require it. Remove BepInEx/patchers/MimicParty.InteropBootstrap.dll to remove the compatibility component. See the included guide for generated-file backups.

[b]Compatibility and testing[/b]
Core 1.0.0 was verified loading in an actual Windows game session with Expansion 1.1.2. The automatic bootstrap is a separate component with its own metadata and regression validation; the earlier session does not establish a fresh-install game test of that new component. Unknown future builds are not guaranteed. Exact fingerprints and validation scope are supplied in the download.
