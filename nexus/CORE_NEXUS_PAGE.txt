FULL DESCRIPTION
Mimic Party Modding Core is a shared runtime foundation for BepInEx-based Mimic Party mods.

It does not replace or redistribute BepInEx. Install the official BepInEx 6 Unity IL2CPP x64 runtime first.

Features:
- Mimic Party build fingerprinting
- GameAssembly executable-section scanner
- unique signature validation before runtime changes
- transactional runtime patches with rollback
- no permanent GameAssembly patching on disk
- shared type/method resolution helpers
- common mod registry/API
- no network communication or auto-updater

Plugin GUID:
com.arribbaa.mimicparty.moddingcore

Other mod authors can declare:
[BepInDependency("com.arribbaa.mimicparty.moddingcore", ">=1.0.0")]

Mods may reference the documented public Core API as an external dependency. The Core DLL itself must not be bundled/reuploaded or modified without permission from arribbaa.

INSTALLATION
1. Install BepInEx 6 Unity IL2CPP x64 build #788 into the folder containing Mimic Party.exe.
2. Start Mimic Party once, then close it.
3. Extract this Core archive directly into the Mimic Party game folder.
4. Confirm BepInEx/plugins/MimicPartyModdingCore.dll exists.
5. Start the game.

VERIFY
Open BepInEx/LogOutput.txt and look for:
Mimic Party Modding Core v1.0.0 by arribbaa loaded.

UNINSTALL
Make sure no installed mod still depends on the Core, then delete BepInEx/plugins/MimicPartyModdingCore.dll.
